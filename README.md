# Ваші субтитри з Google Meet

<img src="icons/icon128.png" width="96" alt="">

Розширення для Chrome, яке зберігає живі субтитри Google Meet у текстовий файл. Meet показує субтитри лише під час дзвінка й ніде їх не зберігає, а це розширення записує їх, поки ви на зустрічі.

**Усе працює локально:** текст нікуди не надсилається, ні на які сервери, і жодних акаунтів не потрібно.

## Що воно робить

- Саме вмикає субтитри, коли ви заходите в дзвінок.
- Записує, хто що сказав і о котрій.
- Коли закриваєте вкладку зустрічі, кладе файл у `Завантаження\meet-transcripts\`.
- Називає файл за датою й назвою зустрічі з Календаря, наприклад `2026-11-10_101349_Планерка_abc-defg-hij.txt`.
- Якщо ви перепідключались або оновлювали сторінку, все одно збирає один файл на дзвінок.
- Кількість записаних реплік видно на іконці розширення. Клік по іконці ще раз завантажує останню стенограму.

Приклад файлу:

```
Google Meet: Планерка (abc-defg-hij) — 10.11.2026, 10:13:49

[10:14:05] Оля Петренко: Доброго ранку, почнемо з дизайну.

[10:14:31] Сергій Саута: Макет готовий, лишились іконки.
```

## Встановлення (2 хвилини)

1. Завантажте архів: зелена кнопка **Code → Download ZIP** угорі цієї сторінки.
2. Розпакуйте його в постійну теку (наприклад `Документи\meet-captions`). Теку потім не видаляйте й не переносьте, бо Chrome бере розширення саме звідти.
3. Відкрийте в Chrome адресу `chrome://extensions`.
4. Праворуч угорі увімкніть **Режим розробника** (Developer mode).
5. Натисніть **Завантажити розпаковане** (Load unpacked) і виберіть розпаковану теку, ту, де лежить `manifest.json`.
6. Готово. Закріпіть іконку на панелі (значок пазла → шпилька), щоб бачити лічильник реплік.

Якщо Meet уже був відкритий, перезавантажувати сторінку не треба: розширення підхопить його саме.

## Оновлення

- Якщо ви завантажували ZIP: завантажте новий архів, розпакуйте його поверх тієї самої теки й натисніть ⟳ біля розширення на `chrome://extensions`.
- Якщо ви робили `git clone`: достатньо `git pull`. Розширення помітить зміни й перезапуститься саме протягом 30 секунд.

## Важливо знати

- **Якість тексту — як у субтитрах Meet.** Розширення записує дослівно те, що показує Meet. Якщо Meet почув слово неправильно, у файлі воно буде неправильним.
- **Репліки діляться за пристроями, а не за голосами.** Якщо двоє говорять в один ноутбук, обидва будуть підписані одним ім'ям.
- **Мова субтитрів** перемикається в самому Meet: ⋮ → Налаштування → Субтитри.
- **Попереджайте співрозмовників**, що ведете стенограму.
- Chrome час від часу показує попередження про розширення в режимі розробника. Це нормально для розширень, встановлених не з Chrome Web Store.

## Для розробників

Код складається з чотирьох файлів без збирання (плюс іконки в `icons/`): `manifest.json`, `lib.js` (склеювання субтитрів і формат файлу), `content.js` (читає субтитри зі сторінки Meet), `background.js` (зберігає файли). Тести запускаються командою `node test.js`.
